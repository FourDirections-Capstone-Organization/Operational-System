# Sub-Module 4.2: Reports & Performance Analytics

## Functional Requirements Covered

| FR ID | Requirement Name | Description | Priority |
|-------|------------------|-------------|----------|
| FR-040 | On-Time / Late KPI Tracking | The system shall classify every completed task as On-Time or Late based on its deadline. KPI figures shall be filterable by employee and date range. Only Coordinators and the Manager shall be able to view KPI tracking reports. | High |
| FR-041 | Export Functions | Coordinators and the Manager shall be able to generate weekly and monthly performance reports exportable in Excel (.xlsx) and PDF (.pdf) formats. Every report export shall be recorded in the Audit Log. | Medium |
| FR-042 | Employee Performance Summary | The report shall display the employee's completed task count, SLA compliance rate, and consolidated Coordinator recommendation history. Accessible only to Coordinators and the Manager. | Medium |

## 1. High-Level Pseudocode

### What We're Building

We need to create a system where:
1. Every completed task is classified as On-Time (completed at or before deadline) or Late (completed after deadline)
2. KPI metrics (on-time rate, late rate) are calculated per employee over a selected period
3. Performance reports can be generated for weekly or monthly periods, filtered by department/employee
4. Reports can be exported as Excel (.xlsx) or PDF (.pdf) files
5. Employee Performance Summary consolidates completed tasks, SLA compliance, and recommendation history
6. All report access is restricted to Coordinators and Managers
7. Report generation does NOT modify any underlying task records

### Step-by-Step Logic

```
STEP 1: Create Report Enums
├── ReportPeriod → Weekly, Monthly
└── ExportFormat → Excel, Pdf

STEP 2: Create Report DTOs
├── KpiTrackingDTO → employee KPI data (on-time count, late count, rates)
├── KpiFilterDTO → employee and date range filters
├── PerformanceReportDTO → report data for export
├── PerformanceReportFilterDTO → period, date range, department, employee, format
├── EmployeePerformanceSummaryDTO → consolidated employee performance data
├── EmployeePerformanceFilterDTO → employee and reporting period
└── ReportExportResultDTO → file bytes, content type, file name

STEP 3: Create Report Service (the "brain" for report logic)
├── GetKpiTrackingAsync(filters, userId, userRole, userDepartmentId) → calculate KPI:
│   ├── Get all completed tasks in date range
│   ├── For each task: compare CompletedAt (UpdatedAt) against Deadline
│   ├── Classify as On-Time (CompletedAt <= Deadline) or Late (CompletedAt > Deadline)
│   ├── Group by employee, calculate rates
│   └── Return per-employee KPI breakdown
├── GeneratePerformanceReportAsync(filters) → generate report data:
│   ├── Determine date range from period (Weekly/Monthly)
│   ├── Get completed tasks in range
│   ├── Calculate performance metrics per employee/department
│   └── Return report data structure
├── ExportReportAsync(reportData, format) → generate file:
│   ├── If Excel → use ClosedXML to create .xlsx
│   ├── If PDF → use QuestPDF to create .pdf
│   └── Return file bytes with content type and filename
├── GetEmployeePerformanceSummaryAsync(employeeId, period, requestUserId, requestUserRole) → consolidate:
│   ├── Get completed tasks for employee in period
│   ├── Calculate SLA compliance rate
│   ├── Get recommendations for employee in period
│   └── Return consolidated summary
└── ValidateReportAccessAsync(requestUserRole) → check Coordinator/Manager role

STEP 4: Create ReportController (the "door" for HTTP requests)
├── GET /api/reports/kpi → get KPI tracking data (Coordinator/Manager only)
├── GET /api/reports/performance → get performance report preview (Coordinator/Manager only)
├── POST /api/reports/export → generate and download report file (Coordinator/Manager only)
└── GET /api/reports/performance-summary/{employeeId} → get employee summary (Coordinator/Manager only)

STEP 5: Install NuGet Packages
├── ClosedXML → for Excel (.xlsx) generation
└── QuestPDF → for PDF (.pdf) generation

STEP 6: Update Program.cs
├── Register ReportService
└── Configure QuestPDF license context

STEP 7: No new database tables needed
└── Uses existing Tasks, TaskAssignments, Users, Recommendations tables
```

## 2. High-Level Explanation of Concepts

### Concept 1: On-Time vs Late Classification (What it is)

**On-Time / Late Classification** compares when a task was completed against its deadline. If the task was completed at or before the deadline, it's On-Time. If after, it's Late.

**Why we use it:**
- Measures employee reliability and time management
- Feeds into SLA compliance tracking (FR-040)
- Provides objective performance data for reviews

**How it works:**
```
CLASSIFICATION RULE:
├── On-Time → Task.UpdatedAt <= Task.Deadline (completed at or before deadline)
└── Late → Task.UpdatedAt > Task.Deadline (completed after deadline)

IMPORTANT: We use the task's UpdatedAt timestamp (when status changed to Completed)
as the "completion time." If the task has a RevisedDeadline, we use that instead.

EXAMPLE:
Task A: Deadline = July 10 5:00 PM, Completed at July 10 3:00 PM → ON-TIME
Task B: Deadline = July 10 5:00 PM, Completed at July 11 9:00 AM → LATE
Task C: Deadline = July 10 5:00 PM, Completed at July 10 5:00 PM → ON-TIME (exactly at deadline)
Task D: RevisedDeadline = July 15, Completed at July 14 → ON-TIME (uses revised deadline)

KPI CALCULATION:
- On-Time Rate = (On-Time Count / Total Completed) × 100
- Late Rate = (Late Count / Total Completed) × 100
- Both rates should sum to 100%
```

**Alternatives:**
- **Buffer-based**: Consider tasks completed within X hours of deadline as "on-time." More forgiving but less precise.
- **Weighted by priority**: Urgent late tasks penalized more than Low priority late tasks. More complex.
- **Business hours only**: Only count business hours for deadline comparison. More accurate but complex.

**Common Mistakes:**
- Using CreatedAt instead of UpdatedAt for completion time
- Not considering RevisedDeadline when it exists
- Including non-Completed tasks in KPI calculations
- Dividing by zero when no tasks are completed (need to handle empty results)

### Concept 2: Report Period Auto-Calculation (What it is)

**Report Period Auto-Calculation** automatically determines the date range based on whether the user selects "Weekly" or "Monthly" as the report period. This removes the need for users to manually calculate date ranges.

**Why we use it:**
- Convenience: users select "Weekly" instead of manually entering start/end dates
- Consistency: ensures all reports use standardized date ranges
- Error prevention: prevents invalid date ranges

**How it works:**
```
WEEKLY PERIOD:
├── Start = Most recent Monday 00:00:00 UTC
└── End = Most recent Sunday 23:59:59 UTC

MONTHLY PERIOD:
├── Start = First day of current month 00:00:00 UTC
└── End = Last day of current month 23:59:59 UTC

EXAMPLE (assuming today is Wednesday, July 13, 2026):
Weekly:
  Start = Monday, July 6, 2026 00:00:00
  End = Sunday, July 12, 2026 23:59:59

Monthly:
  Start = July 1, 2026 00:00:00
  End = July 31, 2026 23:59:59

NOTE: The user can also provide explicit DateRangeStart/DateRangeEnd
to override the auto-calculated period. If explicit dates are provided,
they take precedence over the period auto-calculation.
```

**Common Mistakes:**
- Using the current date instead of the most recent completed week/month
- Off-by-one errors in date range boundaries
- Not handling timezone conversions correctly
- Forgetting to make auto-calculated dates inclusive (start of day to end of day)

### Concept 3: Excel Export with ClosedXML (What it is)

**ClosedXML** is a .NET library for creating Excel (.xlsx) files without requiring Microsoft Office to be installed. It provides a fluent API for creating worksheets, rows, cells, and formatting.

**Why we use it:**
- No Office dependency on the server
- Open-source and well-maintained
- Supports formatting, formulas, and multiple worksheets
- Produces standard .xlsx files that open in Excel, Google Sheets, etc.

**How it works:**
```
1. Create a new XLWorkbook
2. Add a worksheet (e.g., "Performance Report")
3. Write headers in row 1 (bold, colored background)
4. Write data rows starting from row 2
5. Auto-fit column widths
6. Save to a MemoryStream
7. Return the stream as a File() response with content type:
   "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"

EXAMPLE:
| Employee Name | Department | Completed | On-Time | Late | On-Time Rate |
|---------------|-----------|-----------|---------|------|-------------|
| John Doe      | Dispatch  | 20        | 18      | 2    | 90.0%       |
| Jane Smith    | Dispatch  | 15        | 15      | 0    | 100.0%      |
```

**Alternatives:**
- **EPPlus**: Similar library but has a commercial license for newer versions.
- **ExcelDataReader**: Read-only, can't create files.
- **CSV export**: Simpler but no formatting, no .xlsx.

**Common Mistakes:**
- Not disposing the workbook/stream (memory leak)
- Not handling special characters in cell values
- Forgetting to set column widths (columns too narrow)
- Not handling empty data sets (report with no rows)

### Concept 4: PDF Export with QuestPDF (What it is)

**QuestPDF** is a modern .NET library for generating PDF documents using a fluent C# API. It provides layout containers, styling, and pagination out of the box.

**Why we use it:**
- Fluent API makes PDF layout intuitive
- No external dependencies (no wkhtmltopdf, etc.)
- Supports tables, headers, footers, and styling
- Community license is free for small companies / individual use

**How it works:**
```
1. Create a DocumentContainer
2. Define page size (A4) and margins
3. Add header section (report title, date range)
4. Add content section:
   ├── Summary table (total metrics)
   └── Detail table (per-employee breakdown)
5. Add footer (page numbers, generation timestamp)
6. Generate the PDF into a MemoryStream
7. Return the stream as a File() response with content type:
   "application/pdf"

EXAMPLE LAYOUT:
┌─────────────────────────────────────────┐
│ STARS Performance Report                │
│ Period: July 6 - July 12, 2026         │
├─────────────────────────────────────────┤
│ Summary:                                │
│ Total Tasks Completed: 150              │
│ On-Time Rate: 87.3%                    │
│ Late Rate: 12.7%                       │
├─────────────────────────────────────────┤
│ Employee Breakdown:                     │
│ [Table with per-employee KPI data]      │
├─────────────────────────────────────────┤
│ Generated: July 13, 2026 19:00 UTC     │
│ Page 1 of 1                             │
└─────────────────────────────────────────┘
```

**Alternatives:**
- **iText7**: More powerful but complex, AGPL license.
- **DinkToPdf**: HTML-to-PDF conversion. Requires wkhtmltopdf binary.
- **ReportViewer**: Legacy, Windows-only.

**Common Mistakes:**
- Not setting the QuestPDF license context (will show watermark)
- Not handling long text that overflows cells
- Forgetting to dispose streams
- Not testing with empty data sets

### Concept 5: Employee Performance Summary (What it is)

**Employee Performance Summary** is a consolidated report that combines three data sources for a single employee: completed task count, SLA compliance rate, and Coordinator recommendation history.

**Why we use it:**
- Holistic view: combines quantitative (task counts, rates) and qualitative (recommendations) data
- Review support: gives Managers a single report for performance reviews
- Accountability: tracks both output and behavior over time

**How it works:**
```
THREE DATA SOURCES:

1. COMPLETED TASK COUNT:
   - Query tasks WHERE Status = Completed
   - Filter by assignee (via TaskAssignment)
   - Filter by date range
   - Count total

2. SLA COMPLIANCE RATE:
   - From completed tasks, classify On-Time vs Late (per FR-040)
   - Calculate: On-Time Rate = (On-Time / Total) × 100
   - Calculate: Late Rate = (Late / Total) × 100

3. RECOMMENDATION HISTORY:
   - Query Recommendations WHERE AssigneeId = employee
   - Filter by date range
   - Include: Category, Notes, Coordinator name, date
   - Sort by date descending

CONSOLIDATED OUTPUT:
{
  employee: "John Doe",
  period: "July 2026",
  totalCompleted: 20,
  onTimeCount: 18,
  lateCount: 2,
  slaComplianceRate: 90.0,
  recommendations: [
    { category: "Timeliness", notes: "Consistently meets deadlines", date: "2026-07-10" },
    { category: "WorkQuality", notes: "Excellent attention to detail", date: "2026-07-05" }
  ]
}
```

**Common Mistakes:**
- Not filtering recommendations by the same date range as tasks
- Including recommendations for tasks outside the reporting period
- Not handling employees with zero completed tasks (division by zero for SLA rate)
- Not including the Coordinator's name with each recommendation

```csharp
using Microsoft.EntityFrameworkCore;
using ClosedXML.Excel;
using QuestPDF.Fluent;
using QuestPDF.Helpers;
using QuestPDF.Infrastructure;
using Backend.Data;
using Backend.Models;
using Backend.Models.DTOs;
using Backend.Models.Enums;

namespace Backend.Modules.TaskManagement;

public class ReportService : IReportService
{
    private readonly AppDbContext _db;

    public ReportService(AppDbContext db)
    {
        _db = db;
    }

    public async Task<ApiResponseDTO<KpiTrackingDTO>> GetKpiTrackingAsync(
        Guid requestUserId,
        UserRole requestUserRole,
        Guid? requestUserDepartmentId,
        KpiFilterDTO? filters = null)
    {
        var dateStart = filters?.DateRangeStart ?? DateTime.UtcNow.AddMonths(-1);
        var dateEnd = filters?.DateRangeEnd ?? DateTime.UtcNow;

        var query = _db.Tasks
            .Include(t => t.Assignments)
                .ThenInclude(a => a.AssignedUser)
                    .ThenInclude(u => u!.Department)
            .Where(t => t.Status == TaskStatus.Completed)
            .Where(t => t.UpdatedAt >= dateStart && t.UpdatedAt <= dateEnd);

        if (requestUserRole == UserRole.Coordinator && requestUserDepartmentId.HasValue)
            query = query.Where(t => t.AssignedDepartmentId == requestUserDepartmentId.Value);

        if (filters?.EmployeeId.HasValue == true)
            query = query.Where(t => t.Assignments.Any(a => a.AssignedUserId == filters.EmployeeId.Value));

        var completedTasks = await query.ToListAsync();

        if (completedTasks.Count == 0)
            return ApiResponseDTO<KpiTrackingDTO>.Failure("No completed tasks found for the selected criteria.");

        var employeeKpis = completedTasks
            .SelectMany(t => t.Assignments.Select(a => new
            {
                a.AssignedUserId,
                a.AssignedUser,
                IsOnTime = t.UpdatedAt <= (t.RevisedDeadline ?? t.Deadline)
            }))
            .GroupBy(x => x.AssignedUserId)
            .Select(g =>
            {
                var first = g.First();
                var total = g.Count();
                var onTime = g.Count(x => x.IsOnTime);
                var late = total - onTime;

                return new EmployeeKpiDTO
                {
                    EmployeeId = g.Key,
                    EmployeeName = first.AssignedUser is not null
                        ? $"{first.AssignedUser.FirstName} {first.AssignedUser.LastName}".Trim()
                        : "Unknown",
                    EmployeeNumber = first.AssignedUser?.EmployeeNumber ?? "",
                    Department = first.AssignedUser?.Department?.Name ?? "",
                    TotalCompleted = total,
                    OnTimeCount = onTime,
                    LateCount = late,
                    OnTimeRate = total > 0 ? Math.Round((double)onTime / total * 100, 1) : 0,
                    LateRate = total > 0 ? Math.Round((double)late / total * 100, 1) : 0
                };
            })
            .OrderByDescending(k => k.OnTimeRate)
            .ToList();

        var totalCompleted = employeeKpis.Sum(k => k.TotalCompleted);
        var totalOnTime = employeeKpis.Sum(k => k.OnTimeCount);
        var totalLate = employeeKpis.Sum(k => k.LateCount);

        var result = new KpiTrackingDTO
        {
            PeriodStart = dateStart,
            PeriodEnd = dateEnd,
            TotalCompletedTasks = totalCompleted,
            TotalOnTimeTasks = totalOnTime,
            TotalLateTasks = totalLate,
            OverallOnTimeRate = totalCompleted > 0 ? Math.Round((double)totalOnTime / totalCompleted * 100, 1) : 0,
            OverallLateRate = totalCompleted > 0 ? Math.Round((double)totalLate / totalCompleted * 100, 1) : 0,
            EmployeeKpis = employeeKpis
        };

        return ApiResponseDTO<KpiTrackingDTO>.Success(result);
    }

    public async Task<ApiResponseDTO<PerformanceReportDTO>> GeneratePerformanceReportAsync(
        PerformanceReportFilterDTO filters,
        Guid requestUserId,
        UserRole requestUserRole,
        Guid? requestUserDepartmentId)
    {
        var (dateStart, dateEnd) = CalculateDateRange(filters.Period, filters.DateRangeStart, filters.DateRangeEnd);

        var query = _db.Tasks
            .Include(t => t.Assignments)
                .ThenInclude(a => a.AssignedUser)
                    .ThenInclude(u => u!.Department)
            .Include(t => t.AssignedDepartment)
            .Where(t => t.Status == TaskStatus.Completed)
            .Where(t => t.UpdatedAt >= dateStart && t.UpdatedAt <= dateEnd);

        if (requestUserRole == UserRole.Coordinator && requestUserDepartmentId.HasValue)
            query = query.Where(t => t.AssignedDepartmentId == requestUserDepartmentId.Value);

        if (filters.DepartmentId.HasValue)
            query = query.Where(t => t.AssignedDepartmentId == filters.DepartmentId.Value);

        if (filters.EmployeeId.HasValue)
            query = query.Where(t => t.Assignments.Any(a => a.AssignedUserId == filters.EmployeeId.Value));

        var completedTasks = await query.ToListAsync();

        if (completedTasks.Count == 0)
            return ApiResponseDTO<PerformanceReportDTO>.Failure("No records found for the selected period.");

        var employeeBreakdown = completedTasks
            .SelectMany(t => t.Assignments.Select(a => new
            {
                a.AssignedUserId,
                a.AssignedUser,
                IsOnTime = t.UpdatedAt <= (t.RevisedDeadline ?? t.Deadline)
            }))
            .GroupBy(x => x.AssignedUserId)
            .Select(g =>
            {
                var first = g.First();
                var total = g.Count();
                var onTime = g.Count(x => x.IsOnTime);
                var late = total - onTime;

                return new EmployeePerformanceDTO
                {
                    EmployeeId = g.Key,
                    EmployeeName = first.AssignedUser is not null
                        ? $"{first.AssignedUser.FirstName} {first.AssignedUser.LastName}".Trim()
                        : "Unknown",
                    EmployeeNumber = first.AssignedUser?.EmployeeNumber ?? "",
                    Department = first.AssignedUser?.Department?.Name ?? "",
                    Role = first.AssignedUser?.Role.ToString() ?? "",
                    TotalCompleted = total,
                    OnTimeCount = onTime,
                    LateCount = late,
                    OnTimeRate = total > 0 ? Math.Round((double)onTime / total * 100, 1) : 0,
                    LateRate = total > 0 ? Math.Round((double)late / total * 100, 1) : 0
                };
            })
            .OrderByDescending(e => e.OnTimeRate)
            .ToList();

        var totalCompleted = employeeBreakdown.Sum(e => e.TotalCompleted);
        var totalOnTime = employeeBreakdown.Sum(e => e.OnTimeCount);
        var totalLate = employeeBreakdown.Sum(e => e.LateCount);

        string? deptName = null;
        if (filters.DepartmentId.HasValue)
        {
            deptName = await _db.Departments
                .Where(d => d.Id == filters.DepartmentId.Value)
                .Select(d => d.Name)
                .FirstOrDefaultAsync();
        }

        string? empName = null;
        if (filters.EmployeeId.HasValue)
        {
            empName = await _db.Users
                .Where(u => u.Id == filters.EmployeeId.Value)
                .Select(u => $"{u.FirstName} {u.LastName}")
                .FirstOrDefaultAsync();
        }

        var report = new PerformanceReportDTO
        {
            Period = filters.Period,
            DateRangeStart = dateStart,
            DateRangeEnd = dateEnd,
            DepartmentName = deptName,
            EmployeeName = empName,
            TotalCompletedTasks = totalCompleted,
            OverallOnTimeRate = totalCompleted > 0 ? Math.Round((double)totalOnTime / totalCompleted * 100, 1) : 0,
            OverallLateRate = totalCompleted > 0 ? Math.Round((double)totalLate / totalCompleted * 100, 1) : 0,
            EmployeeBreakdown = employeeBreakdown
        };

        return ApiResponseDTO<PerformanceReportDTO>.Success(report);
    }

    public async Task<ApiResponseDTO<byte[]>> ExportReportAsync(
        PerformanceReportDTO reportData,
        ExportFormat format)
    {
        byte[] fileBytes;
        string contentType;
        string fileName;

        switch (format)
        {
            case ExportFormat.Excel:
                fileBytes = GenerateExcelReport(reportData);
                contentType = "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet";
                fileName = $"Performance_Report_{reportData.DateRangeStart:yyyyMMdd}_{reportData.DateRangeEnd:yyyyMMdd}.xlsx";
                break;

            case ExportFormat.Pdf:
                fileBytes = GeneratePdfReport(reportData);
                contentType = "application/pdf";

    public async Task<ApiResponseDTO<EmployeePerformanceSummaryDTO>> GetEmployeePerformanceSummaryAsync(
        Guid employeeId,
        EmployeePerformanceFilterDTO? filters,
        Guid requestUserId,
        UserRole requestUserRole,
        Guid? requestUserDepartmentId)
    {
        var employee = await _db.Users
            .Include(u => u.Department)
            .FirstOrDefaultAsync(u => u.Id == employeeId);

        if (employee is null)
            return ApiResponseDTO<EmployeePerformanceSummaryDTO>.Failure("Employee not found.");

        var dateStart = filters?.DateRangeStart ?? DateTime.UtcNow.AddMonths(-1);
        var dateEnd = filters?.DateRangeEnd ?? DateTime.UtcNow;

        var completedTasks = await _db.Tasks
            .Include(t => t.Assignments)
            .Where(t => t.Status == TaskStatus.Completed)
            .Where(t => t.Assignments.Any(a => a.AssignedUserId == employeeId))
            .Where(t => t.UpdatedAt >= dateStart && t.UpdatedAt <= dateEnd)
            .ToListAsync();

        if (requestUserRole == UserRole.Coordinator && requestUserDepartmentId.HasValue)
            completedTasks = completedTasks
                .Where(t => t.AssignedDepartmentId == requestUserDepartmentId.Value)
                .ToList();

        var onTimeCount = completedTasks
            .Count(t => t.UpdatedAt <= (t.RevisedDeadline ?? t.Deadline));
        var lateCount = completedTasks.Count - onTimeCount;
        var totalCompleted = completedTasks.Count;

        var recommendations = await _db.Recommendations
            .Include(r => r.Coordinator)
            .Where(r => r.AssigneeId == employeeId)
            .Where(r => r.CreatedAt >= dateStart && r.CreatedAt <= dateEnd)
            .OrderByDescending(r => r.CreatedAt)
            .ToListAsync();

        var summary = new EmployeePerformanceSummaryDTO
        {
            EmployeeId = employee.Id,
            EmployeeName = $"{employee.FirstName} {employee.LastName}".Trim(),
            EmployeeNumber = employee.EmployeeNumber,
            Department = employee.Department?.Name ?? "",
            Role = employee.Role.ToString(),
            PeriodStart = dateStart,
            PeriodEnd = dateEnd,
            TotalCompletedTasks = totalCompleted,
            OnTimeCount = onTimeCount,
            LateCount = lateCount,
            SlaComplianceRate = totalCompleted > 0
                ? Math.Round((double)onTimeCount / totalCompleted * 100, 1)
                : 0,
            Recommendations = recommendations.Select(r => new RecommendationSummaryDTO
            {
                RecommendationId = r.Id,
                Category = r.Category.ToString(),
                Notes = r.Notes,
                CoordinatorName = r.Coordinator is not null
                    ? $"{r.Coordinator.FirstName} {r.Coordinator.LastName}".Trim()
                    : "Unknown",
                CreatedAt = r.CreatedAt
            }).ToList()
        };

        return ApiResponseDTO<EmployeePerformanceSummaryDTO>.Success(summary);
    }

    private (DateTime Start, DateTime End) CalculateDateRange(
        ReportPeriod period, DateTime? explicitStart, DateTime? explicitEnd)
    {
        if (explicitStart.HasValue && explicitEnd.HasValue)
            return (explicitStart.Value, explicitEnd.Value);

        var now = DateTime.UtcNow;

        switch (period)
        {
            case ReportPeriod.Weekly:
                var daysSinceMonday = ((int)now.DayOfWeek + 6) % 7;
                var weekStart = now.Date.AddDays(-daysSinceMonday);
                var weekEnd = weekStart.AddDays(6).AddHours(23).AddMinutes(59).AddSeconds(59);
                return (weekStart, weekEnd);

            case ReportPeriod.Monthly:
                var monthStart = new DateTime(now.Year, now.Month, 1);
                var monthEnd = monthStart.AddMonths(1).AddSeconds(-1);
                return (monthStart, monthEnd);

            default:
                var defaultStart = now.AddMonths(-1);
                return (defaultStart, now);
        }
    }
```
