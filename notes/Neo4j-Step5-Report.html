2. The Cypher Query

MATCH (d:Department {id: $departmentId}) MATCH (e:Employee)-[:BELONGS_TO]->(d) WHERE e.availabilityStatus = '0' -- 0 = Active AND e.role IN $eligibleRoleIds -- ["2","3","4"] = Dispatcher, Encoder, Courier WITH e, 1.0 - (e.workload * 1.0 / $maxWorkload) AS workloadFactor, CASE WHEN $classification = 'RoutineDailyTask' THEN e.completedRoutineTasks * 1.0 / $maxXP ELSE e.completedSpecialTasks * 1.0 / $maxXP AS experienceFactor, (e.avgTimelinessScore + e.avgWorkQualityScore + e.avgCommunicationScore) / 3.0 AS recScore RETURN e.id, e.employeeNumber, e.firstName + ' ' + e.lastName, e.role, e.workload, (0.35 * workloadFactor + 0.25 * experienceFactor + 0.40 * recScore) AS suitabilityScore ORDER BY suitabilityScore DESC LIMIT 5

Suitability formula: Score = 0.35 × workloadFactor + 0.25 × experienceFactor + 0.40 × recommendationScore

With zero workload, zero experience, and zero recommendations, the base score is 0.35 (from the workload factor alone). As tasks are created, assigned, completed, and recommendations are submitted, these scores will differentiate employees.
