10. High-Impact Changes (Architectural Notes)

#PatternDescription
10.1Standard pagination patternMost services follow the same pattern: build IQueryable, apply filters, call CountAsync(), then OrderBy().Skip().Take().ToListAsync(), wrap in PaginatedResponseDTO
10.2.Select() projection patternDepartmentService and JobPositionService use .Select() for EF projection. CountAsync() must be called BEFORE the select to avoid shape mismatch
10.3In-memory grouping patternDashboardService.GetWorkloadByDepartmentAsync does in-memory grouping. Skip/Take applied AFTER .ToList() and grouping, not before
10.4Input sanitizationEvery paginated method has Math.Max(1, pageNumber) and Math.Clamp(pageSize, 1, 100) guards to prevent SQL errors from invalid inputs
